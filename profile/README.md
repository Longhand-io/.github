# Nibwrite

The writing studio for Obsidian. Binder, snapshots with side-by-side compare, inspector, corkboard and threads, research, cast, maps, compile, and Nib, the assistant. Everything is stored as Markdown, frontmatter, files, and git commits under an open vault spec, so nothing needs Nibwrite to be read.

Site: https://nibwrite.github.io/nibwrite-site/

## Repositories

| Repo | What it is |
|---|---|
| [nibwrite](https://github.com/nibwrite/nibwrite) | The vault spec, the design, the roadmap and phase ledger, and the Obsidian plugin |
| [scrivener-to-obsidian](https://github.com/nibwrite/scrivener-to-obsidian) | The importer: a Scrivener 3 project in, a spec-following vault out, every snapshot replayed as history. Go, standard library only |
| [nibwrite-site](https://github.com/nibwrite/nibwrite-site) | The website, the brand kit, and shared resources |

## Status

Pre-release. The spec is at version 1, the importer is in progress, the plugin is in design. One maintainer. No stable release yet and no compatibility promise before v1.0.
